Objetivo de aprendizaje

Al terminar este recorrido deberías poder explicar, con tus propias palabras, qué es un estado cuántico, por qué mides y colapsa, qué es el entrelazamiento y por qué el ruido rompe los algoritmos.

  1. Un qubit no es 0 y 1 a la vez “como magia”
    Es un vector de amplitudes. La probabilidad de cada resultado es |amplitud|².
  2. Las puertas rotan ese vector (unitarias)
    Hadamard crea superposición. X es un NOT. CNOT entrelaza dos qubits.
  3. Medir colapsa
    Tras medir, el estado se proyecta. Por eso hacemos muchos “tiros” (shots) y vemos un histograma.
  4. El hardware real es ruidoso (NISQ)
    Pequeños errores destruyen correlaciones y arruinan Grover si el circuito es profundo.
  5. QML ≠ ventaja automática sobre la IA clásica
    Un VQC puede ganar a un modelo lineal; un MLP pequeño suele ser el baseline serio.

Laboratorio 1 · Un qubit y la superposición

Parte de |0⟩. Aplica H (Hadamard): obtienes (|0⟩+|1⟩)/√2. Cada medición da 0 o 1 al 50%. Acumula tiros y mira el histograma.

Circuito y controles

q0: |0⟩ ──[ H ]──[ medida ]──

Prueba esto: Reset → H → Medir varias veces. Luego Reset → H → X → mira las barras (X tras H solo añade una fase global en este caso simple; mejor: Reset → X → H y compara con solo H).

Laboratorio 2 · Entrelazamiento (Bell Φ+)

Circuito: H(q0) y luego CNOT(q0→q1). El estado es (|00⟩+|11⟩)/√2. Las mediciones de ambos qubits siempre coinciden — aunque cada uno por separado sea aleatorio.

Construye el par de Bell

q0: |0⟩ ──[ H ]──●── q1: |0⟩ ─────────⊕──

⟨Z₀Z₁⟩ = +1 significa correlación perfecta en la base computacional. Si vieras |01⟩ o |10⟩ con frecuencia, el entrelazamiento se ha roto (ruido).

Histograma |00⟩ |01⟩ |10⟩ |11⟩

QML vs IA clásica (resultado del repo)

En qml_compare.c comparamos tres modelos sobre los mismos datos 2D: regresión logística, un MLP de 8 neuronas y un VQC de 2 qubits simulado. Accuracy de test típica de esa demo:

Dataset Logística MLP (8) VQC (2q) Lectura didáctica
Blobs (lineal) 100% 100% ~97–100% Basta un modelo lineal
Círculos ~33% 100% ~65% Gana el MLP
XOR ~35% 100% 100% VQC ≈ MLP; ambos superan lo lineal
Mensaje clave: “El VQC gana a la logística en XOR” demuestra frontera no lineal, no que el cuántico derrote a la IA moderna. El baseline serio es el MLP (u otros modelos clásicos).

Dos motores en C · ¿cuál usar?

El repositorio no es un solo simulador: son dos herramientas con nichos distintos.

Statevector · quantum_sim

  • Guarda 2ⁿ amplitudes complejas
  • Cualquier puerta: H, T, Rx, Toffoli…
  • Ruido NISQ y demos QML
  • Límite práctico ~12 qubits

Estabilizadores · stabilizer

  • Tableau Gottesman–Knill O(n²)
  • Solo puertas Clifford (H, S, CNOT…)
  • GHZ de 64 qubits, códigos de error
  • Benchmark hasta cientos de qubits

Memoria: statevector vs tableau (orden de magnitud)

Statevector ≈ 16·2ⁿ bytes. Tableau ≈ O(n²) bits.

Reproduce los demos en tu máquina
